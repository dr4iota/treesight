# Keyboard

Every shortcut the window binds, and there are not many: this is a program made
of pages, so the browser-shaped keys are the ones that work.

| Key | What it does |
|---|---|
| `Alt+Left` | Back |
| `Alt+Right` | Forward |
| `Ctrl+R`, `F5` | Reload, keeping your place |
| `Ctrl+Home` | The start page |
| `Ctrl+O` | Open a folder… |
| `Ctrl+P` | Print |

Text selection, find-in-page and scrolling are the webview's own and are not
touched.

A program built on this one may replace this list wholesale — a page of its own
can need the very keys bound here, and the guard belongs to whoever knows about
that page.
