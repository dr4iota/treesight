# Using treesight

treesight shows a folder as a tree, with whatever you are looking at rendered
beside it. It serves its own pages to its own window, so every view here is a
page: there is a path in the header, Back goes back, and a link is a link.

These pages ship inside the program. They are as current as the build and need
no network, so this folder reads the same on a machine that has never been
online.

- [Opening folders](opening-folders.md) — the start page, Places, Recent, and
  how a folder gets served.
- [Tree and pane](tree-and-pane.md) — the two halves of the window and the
  controls in the header.
- [Reading files](reading-files.md) — what gets rendered, and how to see the
  bytes instead.
- [Preferences](preferences.md) — theme, line numbers, the pane, and printing.
- [Keyboard](keyboard.md) — every shortcut there is.
