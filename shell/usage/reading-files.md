# Reading files

Select a file to see it beside the tree:

- **Source** — syntax highlighted, with line numbers unless you turn them off.
- **Markdown** — rendered, including maths in `$…$` and `$$…$$`, and `mermaid`
  blocks drawn as diagrams.
- **Images**, **audio** and **video** — shown and played in place.
- **PDF** — the platform's viewer.
- **Anything else that is text** — as text.

## Source, Raw, and Download

On Markdown and diagrams, **Source** shows the highlighted source, and
**Rendered** switches back.

**Raw** shows the file itself, with the header still shown, so you can get
back. **Download** saves a copy. A file can also be saved without opening it,
from its row in the folder's table: see **⋯** below.

While a copy is saved, the status line at the bottom says how far it has got,
with **Cancel**.

## A row's ⋯

Each row of a folder's table that has something to offer ends in **⋯**. It
opens a strip under the row: first what is known about it, then what can be
done with it.

- **Download**, on a file, saves a copy, as above.
- **Delete…**, on a computer's own folders, moves the file or folder to the
  Trash (the Recycle Bin on Windows), after asking. Where the Trash will not
  take it, such as a network drive, a file or an empty folder can still be
  deleted for good, asked again in those words; a folder with things in it is
  never deleted that way.

The app may add its own actions to the strip.

## Big files

A text file over 2 MB is not rendered. The page says it is too large, and
offers **View raw** or a download. Video, audio, and large PDFs play without
being read all at once.
