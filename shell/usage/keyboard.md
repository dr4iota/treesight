# Keyboard

On a computer with a keyboard:

| Key | What it does |
|---|---|
| `Alt+Left` | Back |
| `Alt+Right` | Forward |
| `Ctrl+R`, `F5` | Refresh, keeping your place |
| `Ctrl+Home` | The start page |
| `Ctrl+O` | Open a folder… |
| `Ctrl+P` | Print |

Selecting text, finding in the page, and scrolling are left to the system.
