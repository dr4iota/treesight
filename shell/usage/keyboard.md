# Keyboard

On a computer with a keyboard:

| Key | What it does |
|---|---|
| `Alt+Left` | Back |
| `Alt+Right` | Forward |
| `Ctrl+R`, `F5` | Refresh, keeping your place |
| `Ctrl+Home` | The start page |
| `Ctrl+O` | Open a folder… |
| `Ctrl+P` | Print |
| `Ctrl+=`, `Ctrl+−` | Zoom the file in or out |
| `Ctrl+0`, `Ctrl+double-click` | Zoom back to 100% |
| `Ctrl+wheel` | Zoom the file a step at a time |

On a touch screen, pinch the file with two fingers to zoom it. To go back to
100%, hold two fingers still on it: after a moment a note at the top says
*Keep holding to reset view*, then *Release to reset view*, and lifting them
resets it. Moving them first makes it an ordinary pinch.

Selecting text, finding in the page, and scrolling are left to the system.
